# Práctica Refactorización y CI – Procesador de Pedidos

## Descripción
Proyecto Java cuyo objetivo es aplicar técnicas de refactorización, tests unitarios e Integración Continua (CI) utilizando Maven y GitHub Actions.

## Tecnologías utilizadas
- Java 21
- Maven
- JUnit 4
- Git & GitHub
- GitHub Actions
- Eclipse IDE

## Refactorizaciones realizadas
- Eliminación de magic numbers mediante constantes
- Extracción de métodos para mejorar legibilidad
- Renombrado de variables con nombres semánticos
- Separación de responsabilidades

## Tests
He implementado un test unitario para validar el cálculo del total de pedidos, incluyendo descuento, IVA y gastos de envío.

## Integración Continua
He configurado un workflow de GitHub
